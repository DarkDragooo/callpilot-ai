## 2–3 minute demo script

User: “Book a dentist tomorrow afternoon.”

Orchestrator:
- “Checking your calendar… you’re free after 2 PM.”
- “Scanning providers… found several top-rated nearby.”
- “I can start calling now. Say ‘Go’.”

User: “Go.”

Orchestrator:
- “Deploying the swarm. Contacting providers now.”

Dashboard:
- 5 cards update: Dialing → Negotiating → Slot Found
- Once one hits Slot Found, others cancel/grey out

Orchestrator:
- “Best option: 3:30 PM tomorrow at [Provider]. Confirm?”
